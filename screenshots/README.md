# Screenshots (synthetic mockups)

These are **synthetic UI mockups**, not captures of the production application. They exist to
illustrate the products and are populated exclusively with fictional data, no real school, student,
book, or financial information is shown.

| File | Shows |
|---|---|
| [`dashboard.svg`](dashboard.svg) | The platform dashboard, one account with access to Library, Flow, and Budget. |
| [`library-smart-search.svg`](library-smart-search.svg) | Library's natural-language Smart Search, returning results from the collection. |
| [`flow-calendar.svg`](flow-calendar.svg) | Flow's color-coded monthly calendar with upcoming tasks. |
| [`budget-overview.svg`](budget-overview.svg) | Budget's funding sources and spend breakdown for a single budget year. |

All names ("Meadowbrook Middle School Library", "Ms. Rivera"), titles, and dollar figures are
illustrative.

> Want to replace these with real screenshots? Drop PNG files in this directory (using synthetic or
> scrubbed data) and update the table above. The mockups are intentionally standalone SVG so the
> repository renders them on GitHub without any build step.
